# Changelog / Änderungen

## 1.20
- **EN:** New option "Hide the background": the dark background becomes invisible and only text, cover and buttons stay visible. It works together with the opacity slider.
- **DE:** Neue Option "Hintergrund ausblenden": Der dunkle Hintergrund wird unsichtbar, nur Text, Cover und Knöpfe bleiben sichtbar. Sie funktioniert zusammen mit dem Deckkraft-Regler.
- **EN:** Discord: a "Reconnect" button, a more detailed status and a short checklist in the settings.
- **DE:** Discord: ein Knopf "Neu verbinden", ein genauerer Status und eine kurze Checkliste in den Einstellungen.
- **EN:** The volume slider now follows Spotify's volume about four times per second.
- **DE:** Der Lautstärkeregler folgt der Lautstärke von Spotify jetzt etwa viermal pro Sekunde.
- **EN:** Game profiles can only be created for programs that are open right now. Pick one from the list.
- **DE:** Spiel-Profile gibt es nur für Programme, die gerade offen sind. Du wählst sie aus einer Liste.
- **EN:** Several donation links are possible. Put one link per line in donate.txt as Name|https://... and the Donate button shows a small menu.
- **DE:** Mehrere Spenden-Links sind möglich. Pro Zeile ein Link in donate.txt als Name|https://... und der Button "Spenden" zeigt ein kleines Menü.
- **EN:** The OBS browser page looks like the app now (cover, title, artist, progress, times) and always shows "Spotify Overlay by funny.games".
- **DE:** Die OBS-Browserseite sieht jetzt aus wie die App (Cover, Titel, Interpret, Fortschritt, Zeiten) und zeigt immer "Spotify Overlay by funny.games".
- **EN:** New option "Screen sharing": the overlay shows up as a window in Discord's window list (restart needed). The window now has the title "Spotify Overlay".
- **DE:** Neue Option "Bildschirm teilen": Das Overlay erscheint als Fenster in der Fensterliste von Discord (Neustart nötig). Das Fenster heißt jetzt "Spotify Overlay".
- **EN:** Song change animation: a small card with cover, title and artist slides in for a new song (off by default).
- **DE:** Songwechsel-Animation: Bei einem neuen Song gleitet kurz eine kleine Karte mit Cover, Titel und Interpret herein (standardmäßig aus).
- **EN:** Advanced transparency (restart needed): the background can be more see-through than text and cover, with its own opacity slider.
- **DE:** Erweiterte Transparenz (Neustart nötig): Der Hintergrund kann durchsichtiger sein als Text und Cover, mit eigenem Deckkraft-Regler.
- **EN:** Switch version: load the list of versions in Settings -> Updates and install an older or other version if one is buggy.
- **DE:** Version wechseln: In Einstellungen -> Updates die Liste der Versionen laden und eine ältere oder andere Version installieren, wenn eine Fehler hat.
- **EN:** If the connection to Spotify's service fails, the app now tries again automatically once.
- **DE:** Schlägt die Verbindung zum Spotify-Dienst fehl, versucht die App es jetzt automatisch noch einmal.

- **EN:** Click-through mode no longer shows a Windows notification. The orange frame shows that it is on.
- **DE:** Der Durchklickbar-Modus zeigt keine Windows-Benachrichtigung mehr. Der orange Rahmen zeigt, dass er an ist.
- **EN:** New setting "Follow Spotify": the overlay shows while Spotify is running and hides when Spotify is closed.
- **DE:** Neue Einstellung "Spotify folgen": Das Overlay wird gezeigt, solange Spotify läuft, und versteckt, wenn Spotify beendet wird.
- **EN:** New Streamer tab: writes the current song to a text file and offers a web page for OBS (Browser source) with cover, title, artist and progress.
- **DE:** Neuer Streamer-Tab: Schreibt den aktuellen Song in eine Textdatei und bietet eine Webseite für OBS (Browser-Quelle) mit Cover, Titel, Interpret und Fortschritt an.
- **EN:** Playlists without login: copy a playlist link in Spotify and add it to your own list. It opens in Spotify, no Client ID or Premium needed.
- **DE:** Playlists ohne Anmeldung: Einen Playlist-Link in Spotify kopieren und zur eigenen Liste hinzufügen. Sie öffnet sich in Spotify, ohne Client-ID und ohne Premium.

- **EN:** Game profiles: the overlay detects the program in front (for example Roblox or Minecraft) and uses its own size, opacity, popup mode, click-through and position. It goes back to normal when you leave.
- **DE:** Spiel-Profile: Das Overlay erkennt das vorderste Programm (zum Beispiel Roblox oder Minecraft) und nutzt dafür eigene Größe, Deckkraft, Popup-Modus, Durchklickbar und Position. Beim Verlassen geht alles zurück auf normal.
- **EN:** Dodge mode (the overlay turns almost see-through when the mouse is over it) and mini waves that move with Spotify's loudness. Both are off by default.
- **DE:** Ausweich-Modus (das Overlay wird fast durchsichtig, wenn die Maus darüber ist) und Mini-Wellen, die sich zur Lautstärke von Spotify bewegen. Beides ist standardmäßig aus.
- **EN:** The volume step of the volume keybinds can be changed. The volume slider follows Spotify's volume faster.
- **DE:** Der Lautstärke-Schritt der Lautstärke-Tastenkürzel lässt sich einstellen. Der Lautstärkeregler folgt der Lautstärke von Spotify schneller.
- **EN:** In click-through mode the lyrics window ignores the mouse too. Clicking Save in the settings now closes the settings window.
- **DE:** Im Durchklickbar-Modus ignoriert auch das Songtext-Fenster die Maus. Ein Klick auf Speichern schließt jetzt das Einstellungsfenster.

- **EN:** Optional donations: if a donation link is set, the app shows a voluntary "Donate" button in Help & Contact, a short note on the last page of the tour and a link in the update window. The app stays free.
- **DE:** Freiwillige Spenden: Ist ein Spenden-Link eingestellt, zeigt die App einen freiwilligen Button "Spenden" unter Hilfe & Kontakt, einen kurzen Hinweis auf der letzten Seite der Tour und einen Link im Update-Fenster. Die App bleibt kostenlos.

## 1.18
- **EN:** Lyrics window: a button in the overlay opens the lyrics of the current song and follows the song line by line.
- **DE:** Songtext-Fenster: Ein Button im Overlay öffnet den Text des aktuellen Songs und folgt dem Lied Zeile für Zeile.
- **EN:** Click-through mode with a keybind (or the tray menu), so clicks in the game do not hit the overlay.
- **DE:** Durchklickbar-Modus per Tastenkürzel (oder Tray-Menü), damit Klicks im Spiel das Overlay nicht treffen.
- **EN:** Welcome tour on the first start.
- **DE:** Willkommens-Tour beim ersten Start.
- **EN:** Ads are shown in the overlay. Pause is detected correctly, also in the Discord activity (no running timer while paused). Play, pause and next show up much faster.
- **DE:** Werbung wird im Overlay angezeigt. Pause wird richtig erkannt, auch in der Discord-Aktivität (keine weiterlaufende Zeit bei Pause). Play, Pause und Weiter erscheinen viel schneller.
- **EN:** Discord activity shows the album cover. The Discord application ID is built in and can no longer be changed.
- **DE:** Die Discord-Aktivität zeigt das Album-Cover. Die Discord-Anwendungs-ID ist eingebaut und lässt sich nicht mehr ändern.
- **EN:** Playlists also work without Premium: the playlist opens in Spotify.
- **DE:** Playlists gehen auch ohne Premium: Die Playlist wird in Spotify geöffnet.
- **EN:** Better settings with a Save button, size slider and a nicer Help & Contact page. Transparency goes down to 20 % again.
- **DE:** Bessere Einstellungen mit Speichern-Button, Größen-Regler und schönerer Hilfe-&-Kontakt-Seite. Die Deckkraft geht wieder bis 20 % herunter.
